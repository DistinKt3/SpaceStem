# Known Sky: Data and Asset Manifest

Every external dataset and asset used by the game, with source, license and status. Machine-readable details for each processed file (raw input URL, retrieval date, version, SHA-256) are written by the pipeline to `public/data/manifest.json`.

**Status values:** `planned` (not yet fetched), `license-verified` (terms read at the source), `in-use` (shipped in a build).

| Dataset / asset | Source | License / terms | Used for | Status |
|---|---|---|---|---|

Derived star files inherit CC BY-SA 4.0. | Known stars, names (M3) | license-verified |
| JPL DE421 planetary ephemeris | JPL (Folkner, Williams & Boggs, "The Planetary and Lunar Ephemeris DE 421", IPN Progress Report 42-178, 15 Aug 2009; ephemeris dated 2008), obtained via PyPI wheel `skyfield-data` 7.0.0 | JPL ephemeris distribution terms to verify at the source; wheel packaging is MIT | Sun, planets, Pluto, Moon positions (M1) | planned |
| JPL Horizons state vectors | ssd.jpl.nasa.gov (blocked by network policy today) | To verify | Major moons (M1) | planned |
